# User Stories - Devvia

## Epica 1: Autenticación y Perfil
- **HU-01**: Como usuario, quiero registrarme con mi email para acceder a la plataforma.
- **HU-02**: Como usuario, quiero iniciar sesión con Google para agilizar el proceso de acceso.
- **HU-03**: Como usuario, quiero gestionar mi perfil (avatar, habilidades) para mejorar mi visibilidad.

## Epica 2: Catálogo de Proyectos
- **HU-04**: Como desarrollador, quiero subir mi código fuente para mostrar mi talento a la comunidad.
- **HU-05**: Como dueño de un proyecto, quiero poder editar su nombre y descripción para mantenerlo actualizado.
- **HU-06**: Como dueño de un proyecto, quiero poder eliminarlo si decido retirarlo del catálogo.

## Epica 3: Comunidad y Foro
- **HU-07**: Como miembro de la comunidad, quiero comentar en publicaciones para compartir conocimiento o pedir ayuda.
- **HU-08**: Como autor de un comentario, quiero poder editarlo o borrarlo si cometí un error.
- **HU-09**: Como usuario, quiero calificar publicaciones con estrellas para destacar el contenido de valor.

## Epica 4: Empleo y Match
- **HU-10**: Como trainee, quiero ver empleos recomendados según mis habilidades tecnológicas.
- **HU-11**: Como usuario, quiero postularme a vacantes y ver el estado de mis solicitudes.

## Epica 5: Soporte de Chat
- **HU-12**: Como usuario nuevo, quiero chatear con un asistente de soporte para aprender a usar la plataforma.
