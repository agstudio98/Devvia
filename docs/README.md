# Documentación de Devvia 🚀

Bienvenido a la documentación oficial de **Devvia**, la plataforma definitiva para desarrolladores trainee que buscan destacar, conectar y encontrar su primer gran desafío en el mundo tech.

## 🛠 Stack Tecnológico

- **Frontend**: React 19, TypeScript, Tailwind CSS, i18next (Multi-idioma), Lucide Icons.
- **Backend**: Node.js, Express 5, JWT (Autenticación), Multer (Carga de archivos).
- **Base de Datos**: MongoDB (Mongoose).
- **Pruebas**: Jest, Supertest (Backend) y Vitest (Frontend).
